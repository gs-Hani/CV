# CV
My CV and Portfolio in a web and PDF friendly format

## Versioning system:
The system follows the A.B.C.D format where:
*   A: is a complete overhaul update.
*   B: is incremented upon adding a new position.
*   C: is incremented when a new task is added to one or more positions.
*   D: is reserved for minor changes and fixes

## How to run:
since I use my steam deck to develop this tool, I might as well document how to view it locally using said console.
* Just run the following command with your socket of choice:
> python3 -m http.server XXXX
* Then your browser of choice write in the search bar:
> http://localhost:XXXX
